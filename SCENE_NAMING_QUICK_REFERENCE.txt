## Character Substitution Template

For adding new characters, use this template:

```
scene_[action]_[new_character]_[location]_[level]
```

Example for Mayank in kitchen:
```
scene_grabwrist_mayank_kitchen_level1
scene_spank_mayank_kitchen_level3
```

Example for Aman in bathroom:
```
scene_intro_aman_bathroom_level1
scene_sniff_aman_bathroom_level3
```
