# Scene Naming Refactor - Before & After Examples

## Overview of Changes

This document shows concrete before/after examples of the scene naming changes made to your game.

---

## Hallway Scenes - Example Changes

### Before (Unclear, Generic)
```renpy
# In undeclared.rpy
image scene hallway_roman_grab_wrist = "images/Scenes/hallway_roman_grab_wrist.PNG"
image scene hallway_roman_grab_shoulder = "images/Scenes/hallway_roman_grab_shoulder.PNG"
image scene hallway_roman_spank = "images/Scenes/hallway_roman_spank_ass.PNG"

# In roman.rpy
scene expression scene hallway_roman_grab_wrist with dissolve
```

### After (Clear, Scalable)
```renpy
# In undeclared.rpy
image scene_grabwrist_roman_hallway_level1 = "images/Scenes/hallway_roman_grab_wrist.PNG"
image scene_grabshoulder_roman_hallway_level1 = "images/Scenes/hallway_roman_grab_shoulder.PNG"
image scene_spank_roman_hallway_level3 = "images/Scenes/hallway_roman_spank_ass.PNG"

# In roman.rpy
scene expression scene_grabwrist_roman_hallway_level1 with dissolve
```

### What Improved
- ✅ Action name now first: `grab_wrist`, `grab_shoulder`, `spank`
- ✅ Character clearly marked: `roman` (ready for `mayank`, `aman`)
- ✅ Location explicit: `hallway` (different from `watercooler` or `room`)
- ✅ Level progression clear: `level1` (initial) vs `level3` (extreme)

### Before (Ambiguous for Multi-Character)
```renpy

image scene water_bottle_grab_ass = "images/Scenes/water_bottle_grab_ass.PNG"
```

### After (Perfect for Multi-Character)
```renpy
# In undeclared.rpy
```

```renpy
image scene_firstmeet_roman_room_level1 = "images/Scenes/roman_room_first_meet.PNG"
```

## How This Helps with Multi-Character Implementation

### Adding Mayank Character

**Before (Would Be Confusing)**:
```renpy
# Which spank scene is which?
scene messhall_roman_spank          # Roman at mess hall
scene messhall_mayank_spank         # Mayank at mess hall
# Unclear which is which, no level distinction
```

**After (Crystal Clear)**:
```renpy
# Obviously different characters and levels
scene_spank_roman_messhall_level3   # Roman extreme action
scene_spank_mayank_messhall_level2  # Mayank escalation phase
scene_intro_mayank_messhall_level1  # Mayank first meeting
```

### Adding Aman Character in Kitchen

**Before (Would Require New System)**:
```renpy
# No clear pattern for new locations
scene kitchen_aman_spank            # Confusing structure
scene aman_kitchen_something        # Inconsistent with existing
```

**After (Follows Established Pattern)**:
```renpy
# Seamlessly integrates with existing system
scene_intro_aman_kitchen_level1
scene_grabwaist_aman_kitchen_level2
scene_spank_aman_kitchen_level3
```

## Summary of Improvements

### Organization
- 🔹 **Before**: Random structure, inconsistent naming
- 🔸 **After**: Hierarchical, predictable pattern

### Character Scalability
- 🔹 **Before**: No character indicator, would cause confusion with multiple characters
- 🔸 **After**: Character is explicit, ready for Mayank, Aman, others

### Searchability
- 🔹 **Before**: Have to remember exact scene names
- 🔸 **After**: Can grep by action, character, location, or level

### Maintainability
- 🔹 **Before**: Hard to understand the logic of scene names
- 🔸 **After**: Clear naming convention documented and easy to follow

### Future-Proofing
- 🔹 **Before**: Adding new characters would break the naming system
- 🔸 **After**: Just replace `roman` with character name, system still works perfectly
